# GameLib — Библиотека игр и 3D-персонажей

![Django](https://img.shields.io/badge/Django-092E20?style=for-the-badge&logo=django&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-24C4E0?style=for-the-badge&logo=docker&logoColor=white)

Веб-приложение на **Django** для управления коллекцией видеоигр и интерактивного просмотра 3D-моделей персонажей прямо в браузере. Адаптивный интерфейс, поиск и полноценный 3D-обзор моделей.

---

## Ключевые возможности

- **Полный CRUD** для игр и 3D-персонажей (создание, чтение, обновление, удаление)
- **Загрузка медиа**: обложки игр(`.png`, `.jpeg`), превью персонажей (`.png`, `.jpeg`), 3D-файлы (`.glb`)
- **Поиск** по названию игры без перезагрузки страницы
- **Интерактивный 3D-просмотр**:
  - Масштабирование колёсиком мыши
  - Вращение левой кнопкой мыши
  - Сдвиг камеры правой кнопкой мыши
  - Адаптивное модальное окно (95% высоты экрана)
- **Адаптивный дизайн**: корректное отображение на Desktop, Tablet и Mobile
- **Чистый UI**: текстовые кнопки, отсутствие эмодзи, продуманная типографика
- **Docker-контейнеризация**: запуск проекта одной командой
